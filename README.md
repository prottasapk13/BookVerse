# 📚 BookVerse – Online Bookstore Management System

A full-stack online bookstore management system built using the **MERN Stack** (MongoDB, Express.js, React.js, and Node.js). The application allows customers to browse and purchase books online while providing administrators with tools to manage books, categories, inventory, and orders.

---

## 📖 Project Overview

BookVerse is designed to simplify the process of buying books online. Customers can search for books, add them to a shopping cart, and place orders. Administrators can efficiently manage books, users, categories, inventory, and customer orders through an admin dashboard.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/prottasapk13/BookVerse.git
```

### Navigate to the project folder

```bash
cd BookVerse
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```
